# Plan de Mejoramiento – Algoritmia y Programación en Python

## Descripción

Este repositorio contiene el desarrollo de las actividades correspondientes al plan de mejoramiento del área de Algoritmia y Programación en Python del programa de formación ADSO del SENA.

## Objetivo

Fortalecer los conocimientos y habilidades en lógica de programación y desarrollo de algoritmos mediante ejercicios prácticos realizados en Python.

## Organización del repositorio

Los ejercicios están organizados en carpetas según los temas trabajados:

- Tema 1: Algoritmos y análisis de problemas.
- Tema 2: Variables y tipos de datos.
- Tema 3: Entrada y salida de información.
- Tema 4: Operadores aritméticos.
- Tema 5: Operadores relacionales y lógicos.
- Tema 6: Seguimiento, pruebas y corrección de errores.
- Tema 7: Condicional simple (if).
- Tema 8: Condicional doble (if-else).
- Tema 9: Condicional múltiple (if-elif-else).
- Tema 10: Condiciones compuestas y condicionales anidadas.
- Actividad integradora.

## Tecnologías utilizadas

- Python.
- Git.
- GitHub.
